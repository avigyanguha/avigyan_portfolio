# Avigyan Guha | Portfolio

A modern personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS. The site showcases my background, skills, projects, volunteering experience, achievements, and contact details in a visually polished single-page layout.

## Overview

This portfolio is designed to present a clean, professional identity for a Computer Science Engineering student and frontend-focused developer. It includes animated sections, spotlight effects, responsive layout, and a modern dark-themed interface tailored for personal branding.

## Features

- Responsive portfolio landing page
- Animated hero section with strong visual identity
- About section with education and resume link
- Skills grid highlighting technical strengths
- Project showcase cards with GitHub links
- Volunteering and achievements sections
- Contact section for professional outreach
- Footer with quick navigation and social links
- Lightweight Vite setup with fast local development

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Icons
- Base UI utilities

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local Vite URL in your browser (typically http://localhost:5173).

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Available Scripts

```bash
npm run dev      # start the development server
npm run build    # create a production build
npm run preview  # preview the built app locally
npm run lint     # run project linting
```
